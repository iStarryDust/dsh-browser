# @istarry/dsh-browser

Built-in browser plugin: a Playwright-derived Chromium installed under the harness home, stateful browser_open / browser_interact agent tools, and install/detect remotes

本包是 [dsh-browser](https://github.com/iStarryDust/dsh-browser) 的组成部分，由父包 @istarry/dsh-browser 依赖引入，通常不需要单独安装。
